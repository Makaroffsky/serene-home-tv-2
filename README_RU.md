# Serene Home · Xiaomi TV A2 50″

**Версия 1.0-beta2.** Нативный Android TV лаунчер на Java под Xiaomi TV A2 50″ (Android TV 10, 2 ГБ ОЗУ). Основан на концепции CleanFrame, но **не использует код для Tizen**.

**Важный статус:** исходники и браузерный предпросмотр подготовлены; Java-синтаксис, XML, алгоритм идентификации приложений и основные переходы в браузерной демонстрации проверены. **APK в текущей среде не собран: Android SDK/Gradle недоступны. Реального теста на Xiaomi TV A2 не было.** Нельзя обещать работу кнопки Live TV на конкретной прошивке до тестирования.

## Реализовано

- 4 фиксированных ярлыка: **Live TV (антенна)**, **VK Видео**, **Кинопоиск**, **VLC**.
- Работа стрелками пульта и центральной кнопкой OK, подсветка фокуса; крупная типографика.
- Часы/дата по системным часам телевизора.
- Локальный полноэкранный фон 1920×1080; мягкие затемнения и прозрачные плитки без дорогостоящего динамического размытия.
- Кнопки «Все приложения», «Источники» и «Настройки».
- Автообнаружение ТВ-приложений и **ручная привязка каждого ярлыка**, сохранение выбора локально.
- Объявлен обработчик `HOME` и отдельная ТВ-иконка в списке приложений. Назначение HOME зависит от прошивки/настроек Xiaomi — без обещаний автоматической замены.
- Нет доступа к интернету, фоновых сервисов, рекламы, телеметрии, root или команд для отключения системных пакетов.

## Совместимость и ограничения

Официальные характеристики TV A2 50″: 3840×2160, 60 Гц, Android TV 10, quad-core Cortex A55, 2 ГБ ОЗУ. Обои в APK имеют 1920×1080: это осознанно для экономии оперативной памяти, а интерфейс рисуется в текущем разрешении ОС.

На ряде Xiaomi/MediaTek эфирное ТВ связано с `com.mediatek.wwtv.tvcenter`. Этот пакет жизненно важен для тюнера и HDMI, **НИКОГДА его не отключайте**. Лаунчер последовательно пробует общедоступные ТВ-точки входа и отдельно известную точку входа MediaTek; последняя зависит от прошивки и может быть недоступна. Если запуск не получается, появится меню с ручным назначением или системными источниками.

* Пакет VK Видео: `com.vk.tv`.
* Кинопоиск для ТВ: `ru.kinopoisk.tv` (существуют другие версии).
* VLC: `org.videolan.vlc`.

## Получение APK — вариант A (GitHub Actions, без Android Studio)

1. Создайте репозиторий GitHub, например `serene-home-tv`, и загрузите **файлы из корня исправленного ZIP** (не сам архив одним файлом). Проверьте, что `.github/workflows/build-apk.yml` расположен непосредственно в корне репозитория. Самый надёжный вариант — создать скрытый YAML вручную через **Add file → Create new file**. Полная инструкция в `INSTALL_GITHUB_RU.md`.
2. В **Actions → Build Android TV APK** запустите **Run workflow**, либо сделайте push в ветку `main`.
3. Дождитесь успешного шага **Compile debug APK**. Если шаг красный, APK ещё не готов: проверьте журнал, а не устанавливайте неопределённую сборку.
4. Скачайте артефакт **serene-home-apk**. Внутри будет `app-debug.apk`.

GitHub Actions использует JDK 17, Gradle 8.7, Android Gradle Plugin 8.6.1 и SDK 35. Для сборки необходим интернет на GitHub-раннере. На первый запуск тратятся ресурсы для скачивания Android SDK.

## Получение APK — вариант B (локальная Android Studio)

1. Установите актуальную Android Studio с JDK 17 и SDK Platform 35 + Build Tools 35.0.0.
2. Откройте `XiaomiSereneHome` как Gradle-проект. В исходном архиве **нет бинарного gradle-wrapper.jar**, поскольку он не мог быть сгенерирован офлайн. Если студия попросит wrapper, создайте его через установленный Gradle 8.7: `gradle wrapper --gradle-version 8.7` в корне папки.
3. После синхронизации выполните **Build → Build APK(s)**. APK ожидается в `app/build/outputs/apk/debug/app-debug.apk`.
4. На всех этапах проверьте сообщения компилятора, прежде чем передавать APK на ТВ.

## Безопасное первое тестирование на телевизоре

1. Установите APK как обычное приложение с USB-носителя или через `adb install app-debug.apk` (подключение ADB разрешается владельцем телевизора).
2. Откройте Serene Home **из списка приложений**, пока **НЕ назначайте его домашним экраном**.
3. Кнопками пульта проверьте четыре плитки, системные настройки, меню источников и выход из приложений. **Особое внимание — антенному Live TV**.
4. Если Live TV не открывается, зайдите в меню `⚙ → Назначить Live TV` и выберите работающий системный пункт. Для диагностики точек входа смотрите ниже.
5. **Только после проверки** попробуйте стандартный раздел Android `Настройки → Приложения → Приложения по умолчанию → Главный экран` (названия отличаются на Xiaomi). Если такого пункта нет, **не отключайте оригинальный лаунчер** — можно пользоваться Serene Home как обычным приложением.

Вернуться к стандартному состоянию можно через настройки приложения или удалением `Serene Home`. При необходимости команда ADB: `adb uninstall ru.family.serenehome` (она удалит и ваши сохранённые назначения).

## Диагностика ADB без изменения прошивки

```bash
adb devices
adb shell pm list packages | grep -E 'tvcenter|kinopoisk|vk.tv|videolan'
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell am start -n ru.family.serenehome/.LauncherActivity
```

В Windows замените `grep` на `findstr`. Если Live TV не открывается, сохраните **только обезличенный** вывод:

```bash
adb shell dumpsys package com.mediatek.wwtv.tvcenter
```

Не публикуйте серийный номер, MAC-адрес и другие идентификаторы ТВ. По перечню `Activity` и `intent-filter` можно найти точную рабочую точку входа для вашей прошивки.

## Состав проекта

- `app/src/main/java/.../LauncherActivity.java` — основной нативный интерфейс, настройки и запуск приложений.
- `app/src/main/java/.../AppMatcher.java` — логика идентификации, отдельно протестированная через JDK.
- `app/src/main/res/drawable-nodpi/sunset.jpg` — сгенерированный фон.
- `preview.html` — отдельная интерактивная браузерная демонстрация; клавиши ← ↑ → ↓, Enter, Esc. **Не является Android-приложением**.
- `preview.png` — скриншот браузерной демонстрации (ориентир по стилю, не точный скриншот реального ТВ).
- `.github/workflows/build-apk.yml` — воспроизводимая сборка APK.
- `tools/` — Java syntax + matching tests.
