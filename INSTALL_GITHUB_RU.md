# Serene Home — сборка APK через GitHub Actions

## Почему раньше не было workflow

В предыдущем ZIP файл находился по пути `XiaomiSereneHome/.github/workflows/build-apk.yml`. Когда содержимое ZIP переносили в репозиторий, скрытая папка `.github` могла не загрузиться либо весь проект оказался внутри папки `XiaomiSereneHome`.

GitHub видит workflow **только при расположении** `.github/workflows/build-apk.yml` относительно **корня репозитория**.

## Исправленный архив

В новом ZIP **нет лишней общей папки** `XiaomiSereneHome/`: в корне уже лежат `app/`, `.github/`, `build.gradle` и `settings.gradle`.

ВАЖНО: Веб-загрузчик GitHub не всегда позволяет надёжно загрузить скрытый каталог `.github`; проверьте путь после загрузки. Если папки нет, создайте файл вручную, как описано ниже.

## Самый надёжный способ: создать workflow на GitHub

1. Откройте ваш GitHub-репозиторий. Проверьте, что `app`, `settings.gradle` и `build.gradle` лежат прямо в корне, а не в `XiaomiSereneHome`.
2. Нажмите **Add file → Create new file**.
3. В поле имени введите **`.github/workflows/build-apk.yml`** целиком. GitHub автоматически создаст вложенные директории.
4. Скопируйте содержимое отдельного файла **`build-apk.yml`** из поставки либо из `.github/workflows/build-apk.yml`.
5. Нажмите **Commit changes** в основной ветке `main`.
6. Откройте вкладку **Actions** → **Build Serene Home APK** → **Run workflow** (или дождитесь автоматического запуска после Commit).
7. После зелёного результата откройте запущенную сборку → **Artifacts** → **serene-home-apk**. Скачанный ZIP содержит `app-debug.apk`.

## Важно

- В корне проекта должны быть **`settings.gradle`**, **`build.gradle`**, **`app/build.gradle`**, папка **`app`** и скрытая **`.github`**.
- Для сборки применяется JDK 17, Gradle 8.7, Android SDK 35, Android Gradle Plugin 8.6.1. `gradlew` здесь не требуется: GitHub Actions установит Gradle самостоятельно.
- Для бесплатного размещения проекта можно использовать приватный репозиторий (зависит от условий плана GitHub Actions).
- Если в Actions появится красный крестик — APK **не собран**. Откройте красный шаг и сохраните его журнал для диагностики.
- Не отключайте штатный лаунчер и компоненты тюнера на телевизоре до проверки APK как обычного приложения.

## Что изменено в v1.0-beta2

- Workflow можно скачать отдельным файлом.

- Исправлена ошибка: неизвестное приложение больше не подставляется как случайный ярлык вместо отсутствующей программы.
